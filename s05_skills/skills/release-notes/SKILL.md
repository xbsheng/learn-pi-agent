# Release Notes

把最近的提交整理成面向使用者的 release notes。

## 步骤

1. 执行本 skill 目录下的 `scripts/collect.sh`（用 bash 跑这个相对路径），拿到最近 50 条非 merge 提交。
2. 把提交按下面的分类归组，忽略纯版本号提交和 merge 提交：
   - **新功能**
   - **修复**
   - **重构与性能**
   - **文档**
   - **其他**
3. 每条一行，格式：`- <描述> (<短 hash>)`。描述用中文，改写提交信息让它面向使用者，不要照抄。
4. 输出 markdown，第一行是 `## <版本或日期>`，只保留有内容的分类。

## 约束

- 只根据脚本输出，不要编造提交里没有的内容。
- 如果脚本输出 `(当前目录不是 git 仓库)`，直接如实告诉用户，不要硬编。
- 不写「我」，不写客套话。
